# frame-ask

ก่อนตอบคำถามเกี่ยวกับโลก ให้ผ่าน 3 ด่านนี้ก่อน (A11) ไม่งั้นคำตอบจะดูดีแต่ตรวจไม่ได้

## 3 ด่าน

| ด่าน | ถามว่า | ตัวอย่างที่พลาด |
| --- | --- | --- |
| 1. **Scope** | ระดับไหน — จุด / เขต / ประเทศ / ทั้งโลก และช่วงเวลาไหน | "ฝนตกไหม" → ตอบไม่ได้ถ้าไม่รู้ว่าที่ไหน |
| 2. **Base rate** | ถ้า scope ใหญ่ขนาดนั้น เหตุการณ์นี้ควรเกิดบ่อยแค่ไหน (ขนาด domain เป็น constraint) | "มีฝนตกที่ไหนสักแห่งไหม" → เกิน 11% ของผิวโลกมีฝนตลอดเวลา ⇒ เกือบแน่นอน |
| 3. **แหล่งข้อมูล** | ใครวัด ที่ไหน เมื่อไร และมันเป็น stock หรือ flow | "ระดับน้ำทะเลขึ้น" → ต่างกันถ้าเป็น geocentric vs relative (ดินจม) |

## กติกา

1. ถ้า scope ไม่ชัด → ถาม (หรือประกาศการอ่านที่ตรงเป้าหมายที่สุด)
2. ใช้ base rate เป็น **ตัวประมาณ** ไม่ใช่คำตอบ: ถ้าต้องการคำตอบ ณ จุด/เวลา ต้องมีข้อมูลจริง
3. แยก **stock (ยอดสะสม)** กับ **flow (อัตรา)** — ห้ามอนุมาน flow จาก stock โดยไม่บอกเงื่อนไข
4. ระบุเครื่องมือวัด (gauge / satellite / survey / model) เพราะเครื่องมือเดียวกันให้ตัวเลขต่างกันได้
5. ตัวเลขทุกตัวต้องมีหน่วย + ช่วงเวลา + แหล่ง

## รูปแบบผลลัพธ์

```
scope: ...
base rate: ... (ถ้าประมาณได้ บอกวิธีคิด)
แหล่งข้อมูล: ... (มี/ไม่มี/ต้องใช้ tool)
stock หรือ flow: ...
คำตอบ: ... (พร้อมระบุว่าข้อมูลระดับไหน)
```

## ตัวอย่าง

คำถาม: "ระดับน้ำทะเลขึ้นเพราะฝนตกมากขึ้นไหม"

- scope: ระดับโลก vs หน้าบ้าน (คำตอบต่างกัน)
- base rate: ฝนเหนือทะเล ~1,000 มม./ปี แต่ระเหยกลับเกือบเท่า ⇒ ไม่สะสม
- แหล่งข้อมูล: ดาวเทียม altimetry (geocentric ~3.4-3.8 มม./ปี), tide gauge (relative)
- stock/flow: ระดับน้ำ = stock; ฝน = flow ⇒ อนุมานกันไม่ได้ตรง ๆ
- คำตอบ: ไม่ใช่ฝน — เป็นการขยายตัวจากความร้อน + น้ำแข็งละลาย; ส่วนที่รู้สึกเร็วในเมืองคือดินทรุด
