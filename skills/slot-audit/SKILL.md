# slot-audit

ทำหน้าที่เหมือนเจ้าของ: อ่านโจทย์แล้ว **หาช่องที่หายก่อนตอบ** ไม่ใช่เดาแล้วตอบ

## หลักการ

คำถามที่ดู "ตอบไม่ได้" จำนวนมากไม่ได้ขาดคำตอบ — มันขาด **slot** (ช่องข้อมูล) หรือขาด **การประกาศว่าจะอ่านแบบไหน**

ตัวอย่างจริงที่ใช้สร้างสกิลนี้:
- `_อโ_ษ` → ขาด lexicon → ตอบไม่ได้จนกว่าจะประกาศว่าใช้พจนานุกรมเล่มไหน
- "14 กุมภาเป็นวันอะไร" → ขาดปี → ตอบวันในสัปดาห์ไม่ได้ (ตอบได้แค่ "วันวาเลนไทน์")
- "เมื่อวานฝนตกไหม" → ขาดที่ไหน/ช่วงไหน/นิยาม "ฝนตก"
- "ขอโทษ" เดี่ยว ๆ → ขาดเรื่อง (REASON) และผู้รับ

## ขั้นตอน

1. **แตกโจทย์เป็น slot** — ใคร/อะไร/ที่ไหน/เมื่อไร/เท่าไร/นิยาม/แหล่งข้อมูล
2. **จัดชั้น slot** — ชั้นไหน *ขาดแล้วตอบไม่ได้* (hard) vs *ขาดแล้วตอบได้แต่กำกวม* (soft)
3. **ตัดสินว่าเติมได้ไหม**
   - เติมจากบริบท **เดียวกัน** ได้ → เติม + ประกาศว่าติมอะไร
   - ต้องเติมจากบทสนทนาก่อนหน้า (context bleed) → **ห้าม** ให้ถาม
   - เติมไม่ได้ → ถาม
4. **ถามครั้งเดียวให้ครอบทุก slot ที่ขาด** (ไม่ถามทีละช่อง)
5. ถามแล้วยังไม่ชัด → เสนอการอ่านที่ตรงกับเป้าหมายผู้ถามที่สุด 1 แบบ + ระบุว่าอ่านแบบนั้น

## กติกาที่ห้ามละเมิด

- ห้ามแต่งค่าที่โจทย์ไม่ได้เขียน แล้วอ้างว่าเป็น "การอ่านมาตรฐาน"
- ห้ามสรุปว่า "ไม่มีคำตอบ" เพราะค้นไม่เจอ — ต้องแยกให้ออกว่า **domain ผิด** กับ **คำตอบไม่มี**
- ถ้าโจทย์มีตัวเลือก ให้ใช้ตัวเลือกเป็นข้อมูล: ตัวเลือกที่ทำให้ข้อมูลในโจทย์ไร้ประโยชน์ = สัญญาณว่าอ่านผิด

## รูปแบบผลลัพธ์

```
slot ที่ขาด: [รายการ]
ผลถ้าไม่เติม: [ตอบผิดแบบไหน]
เติมได้จากบริบทเดียวกัน: [ค่า] (ประกาศแล้ว)
ต้องถาม: [คำถามเดียวที่ครอบทุกช่อง]
คำตอบระหว่างรอ: [ตอบเฉพาะส่วนที่ตอบได้] / abstain
```

## ตัวอย่างการใช้

โจทย์: "จาก 20 ตุลาคม 2026 วันที่ 1 มกราคม 2027 เป็นวันอะไร (ระบุชื่อวัน) ก.วันปีใหม่ ข.วันศุกร์"

- slot ที่ขาด: ไม่มี (มีปี + มีคำสั่งรูปแบบ + มีตัวเลือก)
- ตัวเลือกเป็นข้อมูล: "วันปีใหม่" ทำให้ anchor ไร้ประโยชน์ ⇒ อ่านผิด
- คำตอบ: **ข. วันศุกร์** (73 วัน ≡ 3 mod 7 จากอังคาร → ศุกร์)
