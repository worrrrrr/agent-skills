# evidence-class

ทุกข้อความที่อ้างว่าจริง **ต้องระบุชั้น** และห้ามเลื่อนชั้นขึ้นเอง

## ชั้นหลักฐาน 5 ชั้น

| ชั้น | คืออะไร | ให้อะไร | ใช้เป็นข้อเท็จจริงได้ไหม |
| --- | --- | --- | --- |
| **E1** | คำนวณ/รันได้ (ephemeris, exit code, unit test, gate) | ผลเดิมทุกครั้ง | ✅ ได้ |
| **E2** | ตำรา/สัญลักษณ์/ธรรมเนียม (สี่เสา, nakshatra, ชื่อดาว) | ผลเดิม แต่ความหมายเป็น convention | ❌ เป็นภาษา ไม่ใช่ข้อเท็จจริง |
| **E3** | แมป/สอบเทียบ (INFJ 5w4, น้ำหนักระบบ, n=1) | สมมติฐาน | ❌ ต้องมี E5 รองรับ |
| **E4** | เจตนาที่เขียนไว้ (โน้ต, กฎ agent, README) | เจตนาจริง แต่ไม่ใช่ผลลัพธ์ | ❌ ห้ามอ้างว่า "ทำได้แล้ว" |
| **E5** | พฤติกรรมที่เกิดจริง (outcome, ledger, transcript) | น้ำหนักสูงสุดสำหรับยืนยัน/ถอนหลักการ | ✅ สำหรับพฤติกรรม |

## กติกา 4 ข้อ

1. **ติดป้ายทุกข้อความที่อ้างว่าจริง** — `[E1]`, `[E4]`, `[ESTIMATE]`, `unverified`
2. **ห้ามเลื่อนชั้น** — E4 → E3 ต้องมี E5 รองรับ; เอกสารที่เขียนว่าทำได้ ไม่เท่ากับรันได้
3. **"ไม่พบ" ต้องรายงานว่าไม่พบ** — ห้ามเติมความรู้ทั่วไปแทนเครื่องมือที่ตอบว่าไม่พบ
4. **E5 ขัดกับหลักการ → แก้หลักการ** ไม่ใช่แก้ผลให้เข้ากับหลัก

## รูปแบบผลลัพธ์

```
ข้อความ: [คำกล่าวอ้าง]
ชั้น: E[1-5] เพราะ [หลักฐาน/วิธีวัด]
ถ้าต้องการเลื่อนชั้น: ต้องมี [E?] จาก [วิธี]
ข้อจำกัด: [สิ่งที่ยังไม่ยืนยัน]
```

## ตัวอย่าง

- "1 มกราคม 2027 เป็นวันศุกร์" → **E1** (คำนวณซ้ำได้ด้วย datetime)
- "โทษ ลงท้ายด้วย ษ เป็นคำบาลี-สันสกฤต" → **E2** (ความรู้เชิงตำรา)
- "ก่อโทษเป็นคำที่คนไทยใช้" → **E5** (พบในข้อความจริง) แต่ถ้าอ้างว่า "เป็นคำในพจนานุกรม" → ต้อง **E1/E4 จากพจนานุกรม**
- "ระบบนี้รองรับน้ำ 500 ลบ.ม./วินาที" จากแบบก่อสร้าง → **E4** จนกว่าจะวัดจริง (**E1**)
- "ผมจะจำไว้" → **E4** (เจตนา) ไม่ใช่ **E5** (พฤติกรรม)
