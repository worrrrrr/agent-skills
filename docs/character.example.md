# แผนที่ที่ไม่มีอยู่ในทะเบียน

*ตัวอย่างตัวละครสมมติ สร้างจากกฎใน `reading.rules.md` — ไม่ใช่บุคคลจริง และไม่ใช่คำพยากรณ์*

---

นภเปิดประตูหอจดหมายเหตุตอนสองทุ่มครึ่ง กลอนดังสองครั้งเหมือนทุกคืน กลิ่นกระดาษเก่ากับกาวแป้งต้อนรับเขาก่อนใคร เพื่อนร่วมงานกลับบ้านหมดแล้ว เหลือหลอดไฟเขียวดวงเดียวเหนือโต๊ะทำงาน ซึ่งเขาไม่เคยเปลี่ยนสี เพราะแสงสีอื่นทำให้เขาอ่านรอยซึมของหมึกผิด

เขาถอดนาฬิกาวางคว่ำลงเหมือนทุกครั้งที่เริ่มงาน

หญิงสาวที่ยืนรออยู่หน้าห้องอ่านไม่ใช่คนที่เขาคุยด้วยเมื่อวาน เธอถือกล่องไม้แบนยาวเท่าแขน สวมรองเท้าที่เต็มไปด้วยโคลนแห้งจากปากแม่น้ำ

“อาจารย์นภใช่ไหมคะ” เธอถาม “ดิฉันชื่อเมธา มาจากสำนักรังวัด”

เขาพยักหน้า ทั้งที่ไม่มีใครเรียกเขาเป็นอาจารย์มานานแล้ว

เธอเปิดกล่อง แผนที่เก่าแผ่นหนึ่งถูกพับตามรอยเดิมจนเป็นสี่เหลี่ยมผืนผ้า ขอบเปื่อยเป็นครีบ ขี้เกลือขึ้นเป็นดอกขาวตรงมุมล่าง—รอยของน้ำที่ขึ้นสูงแล้วไม่ลง

“มันไม่ควรมีอยู่” เมธาพูด “ทะเบียนที่ดินของปากน้ำไม่มีลำคลองสายนี้ แต่แผนที่วาดมันไว้”

นภไม่ตอบ เขาเอียงแผนที่เข้าหาไฟ เขาเห็นเส้นหมึกสองชั้น เส้นหนึ่งเก่า อีกเส้นถูกวาดทับด้วยมือที่มั่นคงกว่า และตรงที่เส้นทั้งสองตัดกัน มีรอยขาดที่ถูกซ่อมด้วยกระดาษต่างสี

“ต้องใช้เวลาสามสัปดาห์” เขาพูด ก่อนที่เขาจะคิดว่าจะใช้เวลานานเท่าไรจริง ๆ

“ได้ค่ะ” เธอตอบเร็วเกินไป “งบมีจำกัด แต่—”

“สามสัปดาห์” เขาพูดซ้ำ แล้วปิดกล่อง

เขาไม่รู้ว่าทำไมตัวเองรับงานนี้ ทั้งที่ชั้นวางข้างฝามีซองรอซ่อมต่อคิวอีกเก้าซอง และเขารู้ดีว่าคนอย่างเขาไม่ควรรับปากอะไรก่อนอ่านเงื่อนไข แต่มีบางอย่างในน้ำเสียงของเมธา—ความเชื่อว่าเขาจะทำได้—ที่ทำให้เขาพยักหน้า และความเชื่อแบบนั้นก็ทำให้เขาโกรธตัวเองในอีกสามชั่วโมงถัดมา

---

คืนที่สี่ เขาเริ่มเห็น

แผนที่ไม่ได้วาดผิด มันวาดสิ่งที่เคยมี ลำคลองที่ถูกถมไปเมื่อห้าสิบปีก่อน แต่ละเส้นมีรอยวัดความลึกเป็นจุดเล็ก ๆ และที่ขอบด้านขวา มีตัวเลขชุดหนึ่งเขียนด้วยหมึกจาง—ระดับน้ำในปีที่น้ำท่วมหนักที่สุด

นภวัดระยะด้วยไม้บรรทัดเหล็ก ซ้ำแล้วซ้ำอีก เขาไม่เชื่อตาตัวเองจนกระทั่งตีสาม

ถ้าตัวเลขนี้ถูก คลองที่ถูกถมไปแล้วคือทางระบายน้ำที่หายไป และระดับน้ำปีนี้จะสูงกว่าที่เขื่อนกันน้ำประเมินไว้เกือบหนึ่งเมตร

เขาควรโทรหาใครสักคน แต่โทรศัพท์อยู่ในลิ้นชัก และเขารู้ว่าถ้าเขาพูดตอนนี้ เสียงของเขาจะสั่น และคนจะได้ยินความกลัวก่อนได้ยินตัวเลข

เขาจึงทำสิ่งที่เขาทำมาตลอด—เขียนมันลงกระดาษ แยกเป็นข้อ ๆ อย่างเป็นระเบียบ แล้วรอให้มีคนถาม

---

การประชุมสำนักรังวัดจัดขึ้นในห้องประชุมชั้นสาม เจ้าหน้าที่สิบเอ็ดคน เก้าคนคุยกันเรื่องงบประมาณ เขานั่งอยู่ปลายโต๊ะ แฟ้มแผนที่วางอยู่ตรงหน้า ยังไม่เปิด

เมธาเหลือบมองเขาเป็นครั้งที่สาม

นภรู้ว่าเขาควรพูดตอนที่หัวข้อเรื่องเขื่อนยังเปิดอยู่ แต่ปากของเขาบอกตัวเองว่า “เดี๋ยวก่อน” เหมือนทุกครั้ง เขารอจังหวะที่คนจะหันมาถาม เขารอต่อไปจนหัวข้อถูกปิด

แล้วประธานก็ถามขึ้นลอย ๆ ว่า “อาจารย์นภมีอะไรจะเสริมไหม”

เขาพูดแค่สามประโยค

ห้องเงียบอย่างที่เขาไม่เคยได้ยินมาก่อน แล้วคนหนึ่งก็หัวเราะเบา ๆ ว่า “อาจารย์คิดมากไปหรือเปล่า แผนที่เก่าขนาดนั้น”

นภยิ้ม เขาเป็นคนที่ยิ้มเก่งเวลาถูกทำให้เจ็บ เขาพูดเล่นกลับไปหนึ่งประโยค—อะไรสักอย่างเรื่องแผนที่ที่อายุมากกว่าคนในห้อง—แล้วทุกคนก็หัวเราะ

เขากลับบ้านตอนเที่ยงคืน ทำงานต่อจนเช้า ไม่ได้กินอะไรนอกจากชาเย็นที่วางอยู่ข้างมือ

---

วันที่สิบเอ็ด เมธามาที่หออีกครั้ง เธอไม่ถามว่าแผนที่เสร็จหรือยัง เธอถามว่า “อาจารย์กินข้าวหรือยังคะ”

เขาตอบว่ายัง

เธอเปิดกล่องข้าวที่ซื้อมา แล้ววางลงบนโต๊ะข้างแผนที่ กลิ่นข้าวกับไข่เจียวทำให้เขารู้ตัวว่ามือสั่น

“ฉันไม่ต้องการให้มันสมบูรณ์แบบ” เธอพูด “ฉันต้องการให้มันถูก”

นภอยากบอกเธอว่าเขารู้ดี—ว่างานที่ถูกแต่ไม่สมบูรณ์แบบคือสิ่งที่เขาเกลียดที่สุด เพราะมันทำให้คนเห็นว่าเขายังไม่พอ แต่เขาไม่ได้พูด เขากินข้าวจนหมด แล้วเช็ดมือบนผ้า ก่อนจะหยิบแผนที่ขึ้นมาอีกครั้ง

คืนนั้น เขาเห็นรอยขาดที่ถูกซ่อม—มันไม่ใช่ความเสียหาย มันคือการแก้ไข มีคนเคยรู้เรื่องนี้มาก่อน และเลือกจะปิดมันไว้

เขาเอาปากกาขึ้นมา แล้วเริ่มเขียนสิ่งที่เขากลัวที่สุดลงในช่องว่างของแผนที่: วันที่น้ำจะขึ้นถึง

---

สิบสี่วันต่อมา เขาส่งแผนที่คืนพร้อมรายงานแปดหน้า ไม่มีคำอธิบายเกินจำเป็น ไม่มีคำขอร้องให้ใครเชื่อ

เมธาโทรมาวันรุ่งขึ้น เสียงของเธอไม่ตื่นเต้น แต่พูดช้า ๆ ว่า “เราจะใช้มัน”

นภวางสาย แล้วนั่งลงที่โต๊ะเดิม หลอดไฟเขียวยังเปิดอยู่ เขามองมือตัวเอง—มือที่แม่นพอจะซ่อมกระดาษอายุร้อยปี แต่ไม่เคยกล้าพอจะพูดก่อนถูกถาม

เขาหยิบโทรศัพท์ขึ้นมา พิมพ์ข้อความถึงเมธา: *ถ้าจะให้อธิบายแผนที่ให้คนอื่นฟัง บอกฉันได้*

แล้วเขาก็กดส่ง ก่อนที่เขาจะเปลี่ยนใจ

---

## Design ledger (กฎ → ฉาก)

| กฎ | ฉากที่แสดง |
| --- | --- |
| ไฟอ่อน/ไม้ scarce → output จำกัด | รับงานเกินกำลัง แล้วหมดแรงหลังทำงานหลายคืน |
| 食神制杀 | ใช้ความแม่นยำ/งานฝีมือจัดการแรงกดดันเรื่องน้ำท่วม |
| 杀印相生 | บทเรียนจากการถูกถาม (“กินข้าวหรือยัง”) ปลดแรงกดดัน |
| Projector รอเชิญ | รอให้ประธานถามก่อนพูด; ไม่เสนอเอง |
| Self-projected authority | พูดสามประโยคแล้วจึงรู้ว่าตัวเองคิดอะไร |
| 7-31 | พูดถูกแต่ห้องเงียบ/ถูกมองว่าคิดมาก |
| Sun H7 + Saturn H1 | ต้องการให้งานถูกเห็น แต่ลงโทษตัวเองเรื่องความสมบูรณ์แบบ |
| Moon H11 | ผูกความหมายกับกลุ่ม/อนาคตของเมือง ไม่ใช่แค่ผลงาน |
| Vedic Moon ลึก | เก็บความกลัวไว้ใต้ความสุภาพ |
