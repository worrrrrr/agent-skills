# Self-model — neutral profile (banded)

โปรไฟล์นี้แปลงค่าจากแบบประเมินเป็น **ระดับ (band)** และตัดข้อมูลระบุตัวตนออก
ใช้เป็นบริบทการตัดสินใจ ไม่ใช่การวินิจฉัยหรือคำพยากรณ์ · พฤติกรรมจริงชนะเสมอ

## 1. ระดับ (bands เท่านั้น)

| มิติ | ระดับ | หลักฐาน |
| --- | --- | --- |
| Openness | สูง | self-report + พฤติกรรมสำรวจ |
| Conscientiousness | กลาง-ต่ำ | self-report; วัดซ้ำด้วยงานที่ปิดจริง |
| Extraversion | ต่ำมาก | self-report + พลังงานหลังสังสรรค์ |
| Agreeableness | สูง | self-report + style การขัดแย้ง |
| Neuroticism | กลาง-ต่ำ | self-report + การรับมือวิกฤตระยะสั้น |
| Typology (ถ้าใช้) | labels แบบ narrative (เช่น MBTI/Enneagram/HD) | ใช้เป็นภาษาสื่อสาร ไม่ใช่ข้อเท็จจริง |
| Instinct stack (ถ้าใช้) | เช่น sx/sp/so | ใช้เป็นสมมติฐาน ไม่ใช่ข้อสรุป |

## 2. กลไกหลัก

```
ความแปลกใหม่/คำถาม
  → ประมวลผลเงียบ ๆ คนเดียวจนเห็นรูปแบบ
  → แปลงเป็นข้อเสนอที่คนรับได้
  → ตัดสินความเสี่ยงต่ำ
  → ลงมือ: ได้ทั้ง "ส่งเร็ว" และ "ค้าง" ขึ้นกับโครงสร้างภายนอก
```

**เงื่อนไขที่ทำงานได้ดี:** เวลาเงียบต่อเนื่อง · อิสระเลือกวิธี · คนที่ไว้ใจให้เถียงด้วย · โจทย์ที่มีความลึก
**จุดตึงภายใน:**
- อยากสำรวจมาก × โครงสร้างงานบาง → เปิดหัวเยอะ ปิดน้อย
- รักษาความสัมพันธ์ × ต้องการถอนตัว → ตอบตกลงก่อน แล้วค่อยหมดแรง
- ทุ่มกับคนใกล้/เรื่องที่อิน × จุดบอดเรื่องเครือข่ายกว้าง

## 3. แก่น

> แปลงสิ่งที่ยุ่งเหยิงให้เป็นภาพเดียวที่เข้าใจได้ แล้วส่งต่อให้คนตรงหน้าเข้าใจด้วย
> (เข้าใจลึก → ทำให้ชัด → ส่งให้คนรับได้)

ไม่ใช่ความสมบูรณ์แบบ ไม่ใช่คำอธิบายทุกด้านของชีวิต

## 4. การวัด

| ตัวแปร | วัดอย่างไร | ข้อจำกัด |
| --- | --- | --- |
| Big Five | แบบสอบถามมาตรฐาน ทำซ้ำทุก 6–12 เดือน | self-report bias, ขึ้นกับช่วงชีวิต |
| Typology | แบบสอบถาม/สำนวน | test-retest ต่ำ ใช้เป็น shorthand |
| คุณภาพงาน | นับงานที่ **ปิด** เทียบงานที่ **เปิด** ต่อสัปดาห์ | ต้องวัดพฤติกรรม ไม่ใช่ความตั้งใจ |
| พลังงาน | ชั่วโมงเงียบ/วัน + เวลาฟื้นหลังสังคม | ต้อง log |
| Conflict style | บันทึกว่าเถียงทันทีหรือเก็บไว้ | self-report มักเข้าข้างตัวเอง |

**หลัก:** ถ้าผลสองเครื่องมือขัดกัน ให้บันทึกทั้งคู่และให้พฤติกรรมตัดสิน

## 5. Robustness

| สถานการณ์ | ปฏิกิริยาที่คาด | จุดที่พัง | ฟื้นด้วย |
| --- | --- | --- | --- |
| deadline รัด + ถูกตัดสมาธิ | ทำได้ระยะสั้นแล้วถอยไปเงียบ | โครงสร้าง/ความต่อเนื่อง | งานชิ้นเล็กที่ปิดได้จริง |
| ถูกวิจารณ์ต่อหน้า | ดูโอเคแล้วเก็บ | พังเงียบ (ไม่แสดง distress) | เวลาคนเดียว + เขียนก่อนคุย |
| สิ่งแวดล้อมเปลี่ยนกะทันหัน | รับมือได้ชั่วคราว | หมดแรงเร็ว | คืนเงื่อนไขเดิม: เวลาเงียบ + คนคุ้น |
| สังคมผิวเผินต่อเนื่อง | ยอมทนแล้วถดถอย | จุดบอดเครือข่ายกว้าง | คุยลึก 1:1 |
| โจทย์ซ้ำไม่มีความลึก | ทำงานได้แต่คุณภาพตก | หมดไฟช้า ๆ | side project ที่สำรวจเสรี |

**Tripwires:** เริ่มเลื่อนงานที่ชอบ · ตอบตกลงเร็วโดยไม่อ่าน · ไม่มีชั่วโมงเงียบเลยแม้แต่วันเดียว

## 6. การใช้ตัดสินใจ

- **งาน:** เลือกงานที่มีความลึก + อิสระ + ส่งผลถึงคน; ระบบ deadline ต้องอยู่ภายนอก (คน/เครื่องมือ/การ commit สาธารณะ)
- **ความสัมพันธ์:** ลงทุนลึกกับคนไม่กี่คน แต่คงจุดเชื่อมกว้างไว้ 1 จุด; บอกความไม่โอเคตั้งแต่ครั้งที่ 2
- **กับดัก:** รู้เยอะแต่ส่งน้อย → นิยาม "เสร็จ" เป็นของจับต้องได้; หลีกเลี่ยงขัดแย้งจนปัญหาโต; ลึกแต่แคบ; เห็นทางแก้คนอื่นชัดกว่าตัวเอง

**ห้ามใช้เป็นข้ออ้าง:** band เป็นค่าเฉลี่ยของอดีต ไม่ใช่ข้อจำกัดของอนาคต
