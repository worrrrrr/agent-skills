# Self-model & 90-day plan — neutral template

เทมเพลตนี้สกัด "โครง" จากแบบจำลองตัวเอง + แผนเป้าหมาย โดยตัดค่าส่วนบุคคลออกทั้งหมด
ใช้เป็นฟอร์มกลางที่แชร์ได้: กรอกเป็น **ช่วง/ระดับ** ไม่ใช่ค่าดิบ และไม่ใส่ข้อมูลระบุตัวตน

> กติกา: ไม่ใช่การวินิจฉัย ไม่ใช่คำพยากรณ์ · พฤติกรรมจริงชนะแบบทดสอบเสมอ · ทุกข้อต้องตรวจซ้ำได้

---

## 0. ข้อมูลที่ห้ามเก็บในไฟล์นี้

ชื่อ-นามสกุล, วันเวลาเกิด, พิกัด/ที่อยู่, เลขสุขภาพ, ประวัติการรักษา, คะแนนิบทดสอบดิบ, ลิงก์บัญชี
ถ้าต้องอ้างอิง ให้เก็บ raw data ไว้ที่อื่น (private) แล้วอ้างเป็นรหัส เช่น `profile-A`

## 3. Mechanics — ทำงานอย่างไร

เติมเป็นวงจรเดียว (ไม่ต้องมีศัพท์จิตวิทยา):

- **Input ที่รับ:** …
- **Processing ที่เกิดซ้ำ:** …
- **Output ที่คนอื่นเห็น:** …
- **จุดที่พังบ่อย:** …
- **เงื่อนไขที่ทำให้ทำงานได้ดี:** …

## 4. Six lenses — คำถามตรวจโมเดล

1. **Ontology** — โมเดลนี้อธิบายอะไร และ *ไม่* อธิบายอะไร
2. **Mechanics** — กลไกที่ทำให้เกิดพฤติกรรมคืออะไร (ไม่ใช่แค่ชื่อ traits)
3. **Essence** — อะไรคือแกนที่ไม่เปลี่ยน แม้บริบทเปลี่ยน
4. **Measurement** — วัดด้วยอะไร, error คืออะไร, วัดซ้ำแล้วได้เดิมไหม
5. **Robustness** — อะไรจะทำให้โมเดลนี้ผิด, เก็บ counter-evidence ที่ไหน
6. **Meaning** — โมเดลนี้มีไว้เพื่อการตัดสินใจอะไร (ไม่ใช่เพื่อนิยามตัวเอง)

## 5. Measurement rules

- ระบุวันที่วัดและเครื่องมือ; ห้ามรวมผลต่างเครื่องมือเป็นค่าเดียว
- เก็บbehavior sample อย่างน้อย 1 อย่างต่อข้อสรุป
- ถ้าผลขัดกัน: บันทึกทั้งสอง แล้วให้พฤติกรรมเป็นตัวตัดสิน
- ทบทวนซ้ำเมื่อ: เปลี่ยนงาน/ความสัมพันธ์, ครบ 90 วัน, หรือมีหลักฐานขัด 2 ครั้ง

## 8. สิทธิ์การใช้งาน

- ไฟล์นี้ใช้เป็น **บริบทการตัดสินใจ** ไม่ใช่คำตัดสินว่าคนเป็นอะไร
- ห้ามใช้ทำนายผลลัพธ์หรือวินิจฉัย
- ถ้าแชร์: ส่งไฟล์นี้ (neutral) ไม่ใช่ raw data
